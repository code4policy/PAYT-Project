# PAYT-Project

## This is a student project with the Harvard Kennedy School of Government for the Mayor's Office of New Urban Mechanics. 

### "data" contains: 
PAYT.Rmd: R Markdown File used for data analysis 
malden_data.xlsx: Data on revenue generated by Malden's PAYT program
payt_panel.png: Initial graph of 5 municipalities with 5 years of pre- and post-PAYT data
paytstart.xlsx: data for municipalities with PAYT programs (trash tonnage, type of PAYT program, number of households, etc.)
trashpopulations.xlsx: 2009-2024 data on all municipalities' trash production, household count, other garbage collection information

### "images" contains: 
Photos of the team, Boston City logos, and other images used for the webpage

### "styles" contains:
CSS code for the website and all pages within

### All other HTML pages:
impacts, index (home), methodoloygy, our-team, recommendations, and sources contain the text content for each page with the same name within the website.
