# PAYT-Project

## This is a student project with the Harvard Kennedy School of Government for the Mayor's Office of New Urban Mechanics. 

### "data" contains: 
<ul>
  <li>PAYT.Rmd: R Markdown File used for data analysis</li>
 <li>malden_data.xlsx: Data on revenue generated by Malden's PAYT program</li>
 <li>payt_panel.png: Initial graph of 5 municipalities with 5 years of pre- and post-PAYT data</li>
 <li>paytstart.xlsx: data for municipalities with PAYT programs (trash tonnage, type of PAYT program, number of households, etc.)</li>
 <li>trashpopulations.xlsx: 2009-2024 data on all municipalities' trash production, household count, other garbage collection information</li>
</ul>

### "images" contains: 
Photos of the team, Boston City logos, and other images used in the website

### "styles" contains:
CSS code for the website and all pages within

### All other HTML pages:
impacts.html, index.html (home), methodology.html, our-team.htlm, recommendations.html, and sources.html contain the text content for each page of the website with the same name
